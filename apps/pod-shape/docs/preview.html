Agent rules

Also in DESIGN_SYSTEM.md §0 and the CLAUDE.md snippet.

1Use only the tokens, components, layouts and icons in DESIGN_SYSTEM.md.
2No raw values: no hex, no bg-[#…], no bg-blue-500.
3Missing something? Stop and ask. Add it only after a yes, and update the doc in the same change.
4Both themes, one primary button per view, status = icon + label.
5Icons only via icons.ts: one meaning, one icon, fixed size/stroke.
6Branch line only in TreeView, PipelineSteps and EmptyState.

Banned patterns

DESIGN_SYSTEM.md §0.1. These make an app look generated.

✕Gradients on text, buttons, backgrounds
✕Glass, blur, glow shadows
✕Sparkles or wand icons for "AI"
✕Emoji anywhere in the UI
✕Card in card, colored left border
✕Blobs, waves, decorative backgrounds
✕Centered hero layouts in the app
✕"Unlock", "Seamlessly", "AI-powered"
✕Lorem ipsum, fake round numbers
✕New font, icon set or UI kit without asking
